# Calculadora de uso mensal de energia
---
Um programa em python com o objetivo de auxiliar no cálculo do consumo elétrico de aparelhos domésticos que utiliza de uma valor fixo de preço para estimar custos mensais e auxiliar na economia financeira e energética.
---
A fórmula utilizada para o cáculo de custo mensal multiplica as horas de uso diário pelos 30 dias de duração mensal e multiplica essa média mensal de uso pelo valor de gasto energético fornecido, assim descobrindo o gasto mensal, que é multiplicado por um preço médio para chegar a uma estimativa de gasto do aparelho em reais.

##Instruções de uso

Para usar o programa execute o app.py e forneça os dados solicitados de uso diário do aparelho, potência em W e o nome do aparelho que serão solicitados, o restante o programa faz sozinho.
